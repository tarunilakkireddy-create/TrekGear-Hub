# TrekGear Hub – Backend Project

## 1. Project Description

TrekGear Hub is a trekking gear management system developed using Node.js, Express.js and SQLite. It helps manage trekking tents, trekkers, rentals and activity logs.

## 2. Technologies Used

- Node.js
- Express.js
- SQLite
- JavaScript
- Postman
- Visual Studio Code

## 3. Installation and Setup

1. Open the project folder in VS Code.
2. Open the terminal.
3. Install the required dependencies:

   ```bash
   npm install
   ```

4. Start the backend server:

   ```bash
   node server.js
   ```

5. The server runs at:

   `http://localhost:5000`

## 4. API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/` | Welcome message |
| GET | `/api/test` | Test database connection |
| GET | `/api/tables` | Display database tables |
| POST | `/api/tents` | Add a new tent |
| GET | `/api/tents` | Get all tents |
| GET | `/api/tents?size=Large` | Search tents by size |
| GET | `/api/tents/:id` | Get a tent by ID |
| PUT | `/api/tents/:id` | Update a tent |
| DELETE | `/api/tents/:id` | Delete a tent |
| GET | `/api/rentals` | Get rental details using SQL JOIN |
| GET | `/api/audit-logs` | Get the latest 10 audit logs |

## 5. Main Features

- Add, view, update and delete tents.
- Automatic tent code generation (TNT-0001, TNT-0002, etc.).
- Tent codes are generated by the server and cannot be changed by clients.
- Input validation for adding and updating tents.
- Search tents by size using query parameters.
- SQLite database integration.
- Rental details retrieved using SQL JOIN.
- Audit logs for ADD, UPDATE and DELETE operations.
- Display the latest 10 audit logs.

## 6. Database Structure

The project uses SQLite with the following tables:

1. **trekkers** – Stores trekker information.
2. **tents** – Stores tent information and automatically generated tent codes.
3. **rentals** – Stores rental information and connects trekkers with tents.
4. **audit_logs** – Stores records of important operations.

The rentals table uses foreign keys to connect with the trekkers and tents tables.

- `README.md` – Project documentation.

## 8. Testing

Postman is used to test the API endpoints.

The following operations have been tested:

- GET – Retrieve tent information.
- POST – Add a tent with an automatically generated code.
- PUT – Update tent details without changing the automatic code.
- DELETE – Delete a tent.
- Validation – Reject invalid input with a 400 Bad Request response.
- Search – Find tents by size.
- SQL JOIN – Retrieve rental details with trekker and tent information.
- Audit logs – Retrieve recent ADD, UPDATE and DELETE activities.

## 9. Conclusion

TrekGear Hub provides a simple backend solution for managing trekking equipment, storing rental information and maintaining activity records through audit logs. It demonstrates REST API development, database relationships, input validation, SQL JOIN operations and automatic tent code generation.
